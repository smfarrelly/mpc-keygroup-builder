# v0.1.0 — software preview

The first tagged release makes the tested command toolkit installable from a
fixed revision instead of a moving `main` branch. This is a software preview,
not a blanket MPC firmware, browser, or hardware compatibility certification.

## Install or switch to the pinned release

```bash
uv tool install --python 3.12 git+https://github.com/smfarrelly/mpc-keygroup-builder.git@v0.1.0
mpc-tools --version
mpc-tools start
```

If an earlier installation already exists, use the same install command with
`--force` to replace the isolated tool environment. That does not modify source
audio, generated instruments, archives, or the SD card. A pinned Git tag stays
pinned: select a later release tag explicitly when you want to upgrade.

For a downloaded wheel, use `uv tool install --python 3.12 PATH-TO-WHEEL` instead.
Compare its SHA-256 with the release's `SHA256SUMS` before installation. The
wheel includes the command modules and packaged schema/starter resources; the
full repository supplies the documentation, recipe library, and examples.
No commercial samples, personal captures, local configs, or generated private
reports are shipped.

## Start with one task

- `mpc-tools start`: goal-based instructions without drive discovery.
- `mpc-tools home --output my-home.html`: a private local starting page; optional
  explicit inputs add favorites, archive notes, and bundle readiness.
- `mpc-project-capture`: preview and capture a saved XPJ with its exact companion
  data into a new verified archive. Source data remains unchanged.
- `mpc-idea-archive`: inspect, search, and restore independent experiment copies.
- `mpc-tools check`: read-only checks of selected programs, archives, or bundles.

See [local home](../local-home.md), [idea snapshots](../idea-snapshots.md), and
[local readiness](../local-readiness.md) for exact arguments and recovery paths.

## Included improvements

Preservation-first colocated Drum coloring, staged instrument rebuilds, explicit
Ableton conversion-loss reporting, offline resume, idea archive integrity and
comparison, independent restore, local evidence browsing, and build-time
recipe freshness for newly generated workstation waves are included. Existing
creative MIDI, declarative controller, catalog, and inspection tools remain
available through `mpc-tools commands`.

## Compatibility and safety boundaries

- Python 3.12 or newer; this release is tested on Linux. Platform-specific
  macOS/Windows execution and MPC/browser runtime checks remain separate.
- Old bundles without build-time recipe receipts report freshness `unknown`.
  Intact files are not evidence of current recipes. Never retrofit receipts to
  disguise stale inputs; rebuild to a new folder.
- Strict archive verification rejects additional unlisted reports. Preserve
  historical captures and reports; make a clean new capture when needed.
- A found XPM is not proof that its WAV references load. Local sample lookup is
  bounded and conservative, not an MPC firmware emulation.
- HTML reports are private point-in-time views. They do not run terminal commands,
  access disks after generation, upload data, or grant hardware acceptance.
  The [browser checklist](../browser-acceptance.md) records the outstanding
  visual/runtime checks separately from automated static safety tests.
- Plugin licensing, current device routing, and listening quality are not inferred.
- There is no automatic SD synchronization, deletion, or existing-project rewrite.

## Developer release checks

Run unit tests, the repository artifact guard, the installed-wheel workflow
smoke test, and the optional reproducibility matrix before publication. The
matrix has a six-case default and an explicit 810-case full mode; each scenario
is generated twice and verified. It removes only its own temporary synthetic
outputs and leaves a local JSON report.

```bash
uv run python scripts/release_matrix.py recipes --output work/release/matrix.json
uv build
uv run python scripts/check_release_artifacts.py --version 0.1.0 dist/mpc_keygroup_builder-0.1.0-py3-none-any.whl dist/mpc_keygroup_builder-0.1.0.tar.gz
```

Artifact inspection checks member paths/types, package version, size bounds,
and prohibited private/captured filename patterns without extraction. It is not
a secret-content scanner or a substitute for reviewing what is tracked in Git.
