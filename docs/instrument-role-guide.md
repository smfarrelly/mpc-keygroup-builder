# Choose an instrument by musical role

Updated October 30, 2026. Paths start at Browser > Places > SD Card.
These are navigation pointers, not relocated XPMs. Keep each program beside
its samples. Save experiments to a new project, preserving the Scratchpad Master.

## Start a groove

- **Main drums — selected:** `00 FG Scratchpad/01 Main Drums/Vinyl SP From Mars 01 FG COLORS.xpm`
- **One-shot variety — accepted:** `00 FG Scratchpad/02 Vinyl Shots/FG Vinyl Shots 04 Eight Bank.xpm`
- **Expressive drums — alternate, hardware pass:** `01 FG Favorites/04 Drum Alternates/09 FG Vinyl Layered Banks 03/FG Vinyl Layered Banks 03.xpm`
  Four velocity layers on Banks A-D; E-H empty. This does not replace the main kit.
- **Texture/percussion — hardware pass:** `01 FG Favorites/04 Drum Alternates/08 FG Breaks Texture Banks 01/FG Breaks Texture Banks 01.xpm`
  F = Found Sounds Body Kit, G = S950 Club 8, H = S950 Hard Glitch.

- **Lead — selected:** `00 FG Scratchpad/05 Lead/Dark FM.xpm`

The October 30 review accepted the two drum alternates and three Wurli voices;
it did not select new favorites. Wurli Bass, Pluck, and Lo-Fi remain separate
untested variants. Do not confuse Wurli Pluck with the selected Pluck Bass.

## Explore outside the selected palette

Colored vendor kits stay at
`Samples/Samples From Mars/<collection>/<original name> FG COLORS.xpm`.
The 88-copy checksum audit proves deployment identity, not 88 hardware passes.
Reference instruments live under `Programs/Keygroups/SFM REFERENCE INSTRUMENTS`.
Their large catalog is not a curated favorites list.

The new [Found Transitions candidate](../inventory/fg-found-transitions-01.md)
is a software-test build, deployed at
`00 FG Hardware Tests/Found Transitions 01/FG Found Transitions 01.xpm`.
Hardware acceptance is pending. It focuses on
impacts and short sweeps instead of another complete drum kit. See that page
for its pad map and deferred listening checks.

For project loading and broader navigation, see [SD navigation](sd-navigation.md).
